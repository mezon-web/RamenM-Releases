# ラーメンスタジオ 🍜

写真風の食材を自由に盛り付けて、ローカルAIの審査員に採点・評論してもらうWindowsゲームです。
具材186種類、スープ24種類、麺20種類、器24種類、香味油・調味料12種類。王道の一杯も、とんでもない創作も作れます。

**[配布版 v0.4.15 をダウンロード](https://github.com/mezon-web/RamenM-Releases/releases/tag/v0.4.15)**

## ダウンロード

どちらも同じゲーム・同じ設定です。違いは、AIモデルが最初から入っているかどうかだけです。

| 配布形態 | ダウンロード | モデルの準備 |
| --- | --- | --- |
| モデルなし版 | [通常ZIP・約217MB](https://github.com/mezon-web/RamenM-Releases/releases/download/v0.4.15/RamenStudio-v0.4.15-win-x64.zip) | 未取得ならアプリから約2.74GBを一度ダウンロード |
| モデル同梱版 | [分割1・約1.50GB](https://github.com/mezon-web/RamenM-Releases/releases/download/v0.4.15/RamenStudio-v0.4.15-with-model-win-x64.zip.001) ＋ [分割2・約1.42GB](https://github.com/mezon-web/RamenM-Releases/releases/download/v0.4.15/RamenStudio-v0.4.15-with-model-win-x64.zip.002) ＋ [展開補助ZIP](https://github.com/mezon-web/RamenM-Releases/releases/download/v0.4.15/RamenStudio-v0.4.15-with-model-extract.zip) | 初回からオフラインで審査可能 |

### モデルなし版の起動

1. 通常ZIPを右クリックし、「すべて展開」を選びます。
2. `ラーメンスタジオ-v0.4.15` フォルダ内の **ラーメンスタジオ.exe** を起動します。
3. AIモデルが未取得なら、上部の **AIの準備** からダウンロードします。取得中も盛り付けできます。

一度取得したモデルは、次回起動やアプリ更新後も使えます。中断したダウンロードは続きから再開できます。
すでに取得済みのモデルがあれば、モデルなし版でも再ダウンロードしません。

### モデル同梱版の起動

1. **`.zip.001`、`.zip.002`、展開補助ZIPの3ファイル**をダウンロードし、同じフォルダへ置きます。
2. 展開補助ZIPだけを右クリックして「すべて展開」します。分割ファイル2つはそのまま残します。
3. 補助フォルダ内の **展開する.cmd** をダブルクリックします。
4. 「準備できました！」と表示されたら、作成された `ラーメンスタジオ-v0.4.15` フォルダ内の **ラーメンスタジオ.exe** を起動します。

追加の展開ソフトや管理者権限は不要です。補助ツールはファイルを確認してから結合・展開します。既存の同名フォルダは上書きしません。展開時は約10GBの空き容量を確保してください。

GitHubの「Source code (zip / tar.gz)」は、このページの説明書と画像です。ゲーム本体は上記の配布ファイルを取得してください。

## 遊び方

- お品書きから器・スープ・麺・具材を選びます。スープと麺は一種類ずつ、具材は好きなだけ追加できます。
- 具材をドラッグで移動。選択枠の端で大きさ、上のツマミで角度を調整できます。反転・削除・手前・奥・沈める・浮かすのボタンも使えます。
- **へい、お待ち！** で審査へ。AIの見立てがまとまったら **詳細評価を見る** を押します。
- **別の評論家に頼む** で、同じ点数と指摘を保った別の評論を楽しめます。
- 写真をPNGで保存したり、レシピファイルを保存・読み込みしたりできます。過去の高評価の一杯は殿堂入りランキングから見られます。

AIが点数、食材の相性、評論、改善案、称号、ヘルシー度の目安と概算カロリーを考えます。食材情報と盛り付けの見え方をもとにしたゲーム上の審査です。

![盛り付けた一杯](assets/ramen.png)

## 必要な環境

- Windows 10 / 11、64bit（x64）。専用GPUは不要です。
- メモリ16GB以上を推奨します。審査時間はPCの性能や空きメモリによって変わります。
- モデルなし版で初回取得を行う場合はインターネット接続が必要です。準備後のプレイ・AI審査・保存はオフラインで動きます。

AIソフトの別途インストール、アカウント、APIキーは不要です。審査のために一杯の情報や画像を外部サービスへ送信しません。
実行ファイルだけを取り出さず、展開したフォルダ全体を保持してください。

## 更新と保存

起動中のアプリを閉じてから、新しい版を別フォルダへ展開して起動してください。
自動保存・殿堂入り・審査結果はPC内に保存され、モデルは `%LOCALAPPDATA%\RamenStudio\models` の共通保存先を再利用します。別PCへ作品を持ち運ぶには、ゲーム内で保存したレシピファイルを使ってください。

配布ファイルのSHA-256は、Releaseの [SHA256SUMS.txt](https://github.com/mezon-web/RamenM-Releases/releases/download/v0.4.15/SHA256SUMS.txt) で確認できます。

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\RamenStudio-v0.4.15-win-x64.zip'
```
